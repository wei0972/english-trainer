# English Trainer

美國日常與旅遊英文單字練習（個人非商業學習用）。主要在 iPhone Safari 使用。

- 單字分層：SUBTLEX-US 影視字幕詞頻覆蓋率、Google Taskmaster／Schema-Guided Dialogue 旅遊對話關鍵度，經人工審定。
- KK 音標：CMU Pronouncing Dictionary 轉換，維基詞典美式音標交叉核對。
- 單字錄音：Wikimedia Commons 真人錄音（多為 CC BY-SA，錄音者見網頁「來源與授權」）；未有錄音者與例句使用瀏覽器內建語音。
- 例句與中譯為本站自寫。
- 學習進度只存在使用者自己的瀏覽器，不會上傳。

完整來源與授權列在網頁內「來源與授權」頁。
